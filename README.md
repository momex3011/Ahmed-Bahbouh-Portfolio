# Ahmed Portfolio Page

Static GitHub Pages portfolio built from the strongest local app screenshots in this workspace.

## Files

- `index.html` - portfolio content and structure.
- `styles.css` - all visual styling, responsive behavior, and print-safe typography.
- `assets/screenshots/` - captured screenshots from selected apps.

## Publish With GitHub Pages

1. Create a GitHub repository, for example `ahmed-portfolio`.
2. Copy the contents of this `portfolio_page` folder into the repository root.
3. Commit and push.
4. In GitHub, open `Settings -> Pages`.
5. Set the source to `Deploy from a branch`, choose `main`, and choose `/root`.

The live URL will usually be:

```text
https://YOUR-GITHUB-USERNAME.github.io/ahmed-portfolio/
```

## Quick Local Preview

Open `index.html` directly in a browser, or run:

```powershell
python -m http.server 8080
```

Then visit:

```text
http://127.0.0.1:8080
```
