01

Al-Nabk Civic Council Platform

This is where the civic platform started. I built the first Al-Nabk system, then kept expanding it into the stronger version it is now: a real portal for organizing projects, proposals, donations, volunteers, users, and public updates.

  • Built the backend with Flask and SQLite, including users, roles, project tracking, voting, calendars, and admin tools.
  • Turned the idea into a complete civic portal with public pages, donation workflows, multilingual support, dashboards, and mobile-ready APIs.
  • Designed it around a practical goal: help council work become easier to manage and easier for residents to follow.
Flask SQLite Auth Flask-Babel Public APIs

Arlington Web + Mobile Civic Platform

I took the civic platform idea and built an Arlington version with both a web portal and a mobile app. The important part is that they are connected: the mobile app pulls from the same backend data through JSON APIs, so updates stay consistent.

Flask Expo React Native JSON APIs English/Spanish
